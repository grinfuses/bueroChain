¿Cómo funciona una Blockchain?
Blockchain
Una blockchain es una lista de bloques encadenados donde cada bloque contiene:
  • Un conjunto de transacciones
  • El hash del bloque anterior (el "eslabón")
  • Su propio hash único
Si modificas un bloque, su hash cambia y rompe toda la cadena que viene después. Esto la hace inmutable.
Concepto clave: inmutabilidad
Hash (SHA-256)
Un hash es una huella digital de datos. SHA-256 convierte cualquier texto en una cadena de 64 caracteres hexadecimales.

Ejemplo: el texto hola siempre produce el mismo hash:
b026324c6904b2a9cb4b88d6d61c81d1…

Cambiar una sola letra produce un hash completamente diferente. Por eso detecta cualquier manipulación.
Concepto clave: determinista y unidireccional
Proof of Work (Minería)
Para añadir un bloque a la cadena hay que resolver un puzzle criptográfico: encontrar un número (el nonce) tal que el hash del bloque empiece por N ceros.

El servidor prueba miles de nonces hasta encontrar uno válido:
a3f8… ✗ no válido
c91b… ✗ no válido
000a… ✓ ¡encontrado!
Esto consume tiempo de CPU, lo que hace costoso falsificar la cadena. En BueroChain la dificultad es de 3 ceros.
Concepto clave: coste computacional = seguridad
Cartera y Dirección
Cada usuario tiene una dirección única que funciona como un número de cuenta bancaria, pero pública.

En Bitcoin real, la dirección se genera a partir de una clave pública. En BueroChain es un UUID que identifica tu cartera.

El balance no se guarda en ningún sitio: se calcula recorriendo todas las transacciones confirmadas de la cadena.
Concepto clave: UTXO vs saldo calculado
Transacciones y Mempool
Al enviar BUERO, la transacción va primero a la mempool (memoria de transacciones pendientes). No es definitiva.

Cuando alguien mina un bloque, toma las transacciones de la mempool, las incluye en el bloque y las confirma para siempre en la cadena.

El minero recibe una recompensa de red (+{{ mining_reward if mining_reward is defined else 10 }} BUERO) como incentivo, creada de la nada. Así es como se emite nueva moneda.
Concepto clave: confirmaciones y consenso
Bloque Génesis
El Bloque #0 es el origen de toda la cadena. Es especial porque no tiene hash anterior válido (se pone 0).

Bitcoin tiene su propio bloque génesis minado por Satoshi Nakamoto el 3 de enero de 2009, con el mensaje oculto: "Chancellor on brink of second bailout for banks" — una crítica al sistema bancario tradicional.
Concepto clave: origen inmutable de la cadena
NFT — Token No Fungible
Un NFT es un token único e irrepetible. A diferencia de los BUERO (donde 1 BUERO = 1 BUERO), cada NFT es distinto y tiene un identificador único.

En BueroChain cada NFT tiene un Token ID generado con SHA-256:
SHA256(nombre + dirección + timestamp)
Cambiar cualquier carácter del nombre produce un Token ID completamente diferente. Eso lo hace irrepetible.
Concepto clave: unicidad criptográfica
Arte generativo en NFTs
Cuando no subes una imagen, el arte del NFT se genera automáticamente a partir de su Token ID:
  • Los primeros 18 caracteres → 3 colores CSS
  • Los caracteres 18-20 → ángulo del gradiente
  • Caracteres siguientes → posición de figuras
Resultado: cada NFT tiene un aspecto visual único, derivado matemáticamente de su hash. Dos NFTs con el mismo nombre pero diferente propietario tendrán arte diferente.

Esto es similar a cómo proyectos como CryptoPunks o Bored Apes generan sus imágenes a partir de atributos almacenados en la blockchain.
Concepto clave: datos on-chain → arte determinista
Minteo y propiedad
Mintear un NFT significa crearlo y registrarlo en la cadena. En BueroChain:
  • Cuesta 5 BUERO (tarifa de red)
  • La tarifa va a nft_contract (se "quema")
  • El NFT aparece inmediatamente en la galería
  • La tarifa queda pendiente hasta que se mine un bloque
La propiedad se registra en la base de datos. Cuando transfieres un NFT, el campo owner_address cambia al nuevo propietario.

En Ethereum real, la propiedad se gestiona en un smart contract (ERC-721) y es inmutable en la blockchain.
Concepto clave: propiedad digital verificable
